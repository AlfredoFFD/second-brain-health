Privacy policy

Last updated: September 27, 2026

second-brain-health is a personal tool used by one person, its owner. This policy covers how it handles Google user data.

What it accesses

With the owner's consent, it reads (read-only) the owner's own Google Health data: sleep, activity and fitness, and health metrics and measurements. It cannot write, change or delete any data.

How the data is used

The data is used for one purpose only: saving a daily summary to the owner's private notes on the owner's own computer, so the owner can track their own sleep and training. It is not used for advertising, profiling, or training AI or machine-learning models.

Storage

Data and access tokens are stored only on the owner's own computer. Nothing is stored on any server run by this tool, because it has none.

Sharing

Google user data is not sold, shared with or transferred to any third party. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local files removes the stored data.
